# LaborForce Medical Management — Cook County Health briefing

Executive briefing deck proposing a 90-day TPL/Workers' Compensation revenue-recovery pilot at John H. Stroger, Jr. Hospital.

- `index.html` — the self-contained web deck (no external requests). Open it directly or view it on GitHub Pages.
- `LaborForce_CookCountyHealth.pptx` — the PowerPoint version of the same four slides (the eight-slide version is on branch `deck-8-slides`).
- `build_refined.py` — regenerates `index.html` from the original export (`original_backup.html`, not committed) and the brand assets in `brand/`.
- `prepare_logo.py` — cuts the LaborForce logo into the transparent mark and lockup used by the deck.

Keyboard: ← / → to move between slides, Home / End for first and last, F for full screen via the button, and "Print report" (or Ctrl+P) opens the prepared PDF `LaborForce_CookCountyHealth.pdf`, exported from the PPTX and embedded in `index.html`.

Cover photo: modern medical centre from Unsplash (photo UN1qX9JB_l0, name sign cropped out), used under the Unsplash License; cropped and colour-graded into `brand/hospital_cover.jpg`.
